Mettre la page 3D en ligne (une seule fois)

  1. Télécharge la page 3D :
  2. Sur github.com, crée un dépôt public nommé peluches, puis Add file → Upload files et dépose index.html.
  3. Dans Settings → Pages, choisis la branche main et clique Save. Une ou deux minutes après, ton adresse est https://ton-pseudo.github.io/peluches/.
  4. Colle cette adresse dans « Adresse de ta page 3D ». Elle reste enregistrée dans ce navigateur. Chaque peluche est entièrement décrite dans son lien : rien d'autre à mettre en ligne.

Dans « Créer une image item »

  1. Type d'item : Site Web, puis colle le lien de la peluche dans URLS.
  2. Pour l'icône d'inventaire : télécharge l'icône PNG, mets-la sur imgg.fr et colle son lien dans Icône URL personnalisé.
